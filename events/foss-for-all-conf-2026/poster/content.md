FOSS for All Conference 2026 poster: content
============================================

Copy for the A0 portrait poster (841×1189 mm) shown at FOSS for All Conference
2026 (November 28, 2026, AWS Korea), in the order it appears on the poster.
*body.html* is the source of truth for the typeset copy; this document mirrors
it for review.  Korean copy is written in mixed script; the build runs it
through Gukhanmun, which adds every hangul reading as ruby.  English copy
follows each Korean block.

Reading distances: **3 m** for the masthead and the conversion strip, **1 m**
for section headings and examples, **30 cm** for body text, notes, install
commands, and credits.

Every conversion example below was checked against `gukhanmun` built from this
branch (0.4.0).  *dictionary.tsv* adds the poster's own entries for words the
bundled dictionaries split: 對應表 (대응표) and 異體字 (이체자).

### What is mixed-script Korean?

KO heading: 國漢文混用體란?

> 國漢文混用體는 漢字語를 漢字로, 固有語와 助詞·語尾를 한글로 섞어 쓰는
> 表記法입니다. 20世紀 내내 新聞과 書籍, 學術 論文에 널리 쓰였습니다. 그러나
> 只今의 讀者 大部分은 漢字를 넉넉히 배우지 못했기 때문에, 이 時期의 記錄은
> 韓國語 母語 話者에게도 읽기 어렵습니다.

> Korean has its own alphabet, hangul. For most of the 20th century, though,
> newspapers, books, and scholarship wrote Sino-Korean words in hanja (Chinese
> characters), keeping hangul for native words and grammatical endings. This
> is mixed-script Korean, 國漢文混用體 (gukhanmun honyongche). Most Korean
> readers today learned few hanja at school, so decades of printed records are
> hard to read even for native speakers.

Why not just a lookup table?
----------------------------

KO heading: 單純한 對應表로는 안 되는 理由

Five cards, each with a label, examples, and a note.

| KO label           | EN label                   | Examples               | Output                           |
| ------------------ | -------------------------- | ---------------------- | -------------------------------- |
| 한 글字, 여러 讀音 | One character, many sounds | 音樂 · 快樂 · 樂山樂水 | 음악 · 쾌락 · 요산요수           |
| 頭音法則           | Initial sound law          | 李舜臣 · 女子          | 이순신 · 여자                    |
| 格子 分割          | Lattice segmentation       | 行事場所               | 行事 + 場所, not 行事場 + 所     |
| 外來語             | Loanwords                  | 北京 · 東京            | 베이징 · 도쿄                    |
| 同音異義語         | Homophones                 | 詐欺 · 士氣 · 史記     | 사기(詐欺) 사기(士氣) 사기(史記) |

Card notes:

 -  樂은 單語에 따라 악·락·요로 읽힙니다.
    / 樂 reads 악 (*ak*), 락 (*rak*), or 요 (*yo*) depending on the word.
 -  韓國 正書法에서는 單語 첫머리의 ㄹ·ㄴ이 바뀝니다.
    / Word-initial ㄹ and ㄴ change in South Korean orthography.
 -  가장 긴 一致를 먼저 고르지 않고, 辭典 一致의 格子에서 最適의 分割을
    찾습니다.  / Gukhanmun finds the best split over a lattice of dictionary
    matches, not the longest match first.
 -  地名은 國立國語院 外來語 表記 用例를 따릅니다.
    / Place names follow the NIKL loanword spelling examples.
 -  讀音이 겹치면 漢字를 自動으로 남깁니다.
    / When readings would collide, Gukhanmun keeps the hanja automatically.


Five ways to render
-------------------

KO heading: 다섯 가지 出力 方式

The same sentence in each mode (Constitution of the Republic of Korea,
Article 1, Paragraph 1).

| KO label   | EN label       | Output                                             |
| ---------- | -------------- | -------------------------------------------------- |
| 한글 專用  | Hangul only    | 대한민국은 민주공화국이다.                         |
| 한글(漢字) | Hangul (hanja) | 대한민국(大韓民國)은 민주(民主)공화국(共和國)이다. |
| 漢字(한글) | Hanja (hangul) | 大韓民國(대한민국)은 民主(민주)共和國(공화국)이다. |
| 루비       | Ruby           | 大韓民國은 民主共和國이다. (with ruby readings)    |
| 原文 維持  | Original       | 大韓民國은 民主共和國이다.                         |

Note: 이 포스터의 讀音도 Gukhanmun의 루비 出力으로 달았습니다.
/ The hangul readings above the hanja on this poster were generated by
Gukhanmun's ruby output.


Built-in dictionaries
---------------------

KO heading: 內藏 辭典

《標準國語大辭典》

 -  KO: 國立國語院이 編纂한 規範 辭典. 約 50萬 表題語.
 -  EN: *Standard Korean Language Dictionary*: NIKL's normative dictionary,
    the reference for standard spelling. About 500,000 entries.

《우리말샘》

 -  KO: 누구나 參與하는 開放型 辭典. 100萬 餘 表題語로 現存 最大 規模.
 -  EN: *Open Korean Dictionary*: the largest Korean dictionary, open to
    public contributions. Over one million entries.

外來語 表記 用例

 -  KO: 北京 → 베이징처럼 外來語 讀音의 根據.
 -  EN: *NIKL loanword spelling examples*: the source for readings such as
    北京 → 베이징.

Thanks box:

 -  KO: 國立國語院이 2019年 두 辭典을 CC BY-SA 2.0 KR로 公開한 德分에

Install
-------

KO heading: 設置

Platforms: 命令줄 道具 (CLI), Rust, WebAssembly, Node-API, Python (0.4.0 新規)

 -  KO: 平文 텍스트·HTML·Markdown을 그대로 變換합니다.
 -  EN: Converts plain text, HTML, and Markdown, from one Rust engine.

~~~~ sh
mise use -g aqua:dahlia/gukhanmun
winget install HongMinhee.Gukhanmun
cargo install gukhanmun-cli
pip install 'gukhanmun[stdict]'
npm add @gukhanmun/wasm \
        @gukhanmun/stdict-fst
~~~~

 -  KO: `.deb`·`.rpm`·Homebrew·Arch Linux 等 더 많은 패키징을 準備 中입니다.
    寄與 歡迎!
 -  EN: More packages are on the way: .deb, .rpm, Homebrew, Arch Linux, and
    more. Contributions welcome!
