設置
====

Gukhanmun은 같은 API를 共有하는 두 個의 JavaScript 具顯을 提供합니다:

| 패키지            | 環境                                       | 備考                          |
| ----------------- | ------------------------------------------ | ----------------------------- |
| `@gukhanmun/wasm` | 브라우저, Node.js 20+, Deno 2.0+, Bun 1.0+ | 넓은 互換性을 爲해 勸奬        |
| `@gukhanmun/napi` | Node.js 20+, Deno 2.0+, Bun 1.0+           | 서버에서 더 빠름; 네이티브 코드 |

大部分의 프로젝트에서는 `@gukhanmun/wasm`을 使用합니다.  處理量이 重要한 서버
作業負荷에는 `@gukhanmun/napi`로 바꿉니다.


WebAssembly
-----------

大部分의 環境에서 WebAssembly 具顯이 最善의 選擇입니다.  브라우저·Node.js·Deno·Bun
에서 動作하며 네이티브 코드를 必要로 하지 않습니다.  選好하는 패키지 管理者로
設置합니다:

<PackageManagerTabs
  command={{
    npm: "npm add @gukhanmun/wasm",
    yarn: "yarn add @gukhanmun/wasm",
    pnpm: "pnpm add @gukhanmun/wasm",
    bun: "bun add @gukhanmun/wasm",
    deno: "deno add jsr:@gukhanmun/wasm",
  }}
/>


Node-API
--------

네이티브 애드온과 함께 Node.js·Deno·Bun을 쓰려면:

<PackageManagerTabs command="add @gukhanmun/napi" />



標準國語大辭典
--------------

JavaScript 패키지는 《標準國語大辭典》을 內藏하지 않습니다.  別途로 設置합니다:

<PackageManagerTabs
  command={{
    npm: "npm add @gukhanmun/stdict-fst",
    yarn: "yarn add @gukhanmun/stdict-fst",
    pnpm: "pnpm add @gukhanmun/stdict-fst",
    bun: "bun add @gukhanmun/stdict-fst",
    deno: "deno add jsr:@gukhanmun/stdict-fst",
  }}
/>

<PackageManagerTabs
  command={{
    npm: "npm add @gukhanmun/stdict-cdb",
    yarn: "yarn add @gukhanmun/stdict-cdb",
    pnpm: "pnpm add @gukhanmun/stdict-cdb",
    bun: "bun add @gukhanmun/stdict-cdb",
    deno: "deno add jsr:@gukhanmun/stdict-cdb",
  }}
/>

두 패키지는 같은 辭典을 담고 있습니다; 두 形式은 찾기 特性에서 差異가 납니다.  大部分의
用例에서는 FST 패키지를 選好합니다.


NAPI 플랫폼 바이너리
--------------------

`@gukhanmun/napi`는 다음을 爲한 미리 빌드된 바이너리를 包含합니다:

 -  macOS: ARM64, x86\_64
 -  Windows: ARM64, x86\_64
 -  Linux (glibc): ARM64, x86\_64

Alpine Linux(musl)는 소스에서 빌드해야 합니다.
