Python
------

Python API는 `Converter(...)`, 標準 라이브러리 列擧型과 變更할 수 없는 設定
레코드를 使用합니다. [Python API 參考 文書](./python.md)나
[Python 빠른 始作](../guide/python/start.md)을 參考하세요.
