Support Gukhanmun
=================

<div className="sponsorship-page">

<div className="sponsorship-intro">

Korean text, easier to read. Free software, built to share.

</div>

Gukhanmun converts hanja (Chinese characters used in Korean writing) into
hangul (the Korean alphabet). For readers unfamiliar with hanja, a few
characters can interrupt an otherwise readable passage. Gukhanmun helps
remove that barrier, with options to keep the original characters alongside
their readings.

You can support the project's ongoing development and maintenance through
either of these funding channels.

<FundingChannels />


What your support makes possible
--------------------------------

Maintaining a text conversion tool takes work beyond its first release.
Donations help sustain improvements to conversion accuracy, bug fixes, and
documentation that makes the software easier to use and integrate.

Gukhanmun works with plain text, HTML, and Markdown. It is available as a
command-line tool and as a Rust library, with bindings for JavaScript and
TypeScript. Your support helps maintain these ways of using the same free
and open source software.
